# Hone Pointer releases

Downloads and the update feed for Hone Pointer, a Mac app for mice and trackpads.

- **Download:** the newest DMG is under [Releases](https://github.com/themavik/hone-pointer-releases/releases/latest).
- **Updates:** Hone Pointer checks `appcast.xml` in this repository once a day (Settings → Check for updates automatically). Every download is signed; the app refuses one that is not.
- **Problems:** open an issue here.

The app's source code is not in this repository.
